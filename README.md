# ReVive website

The public pages of ReVive · A Fresh Start, served by GitHub Pages at https://and-games-studio.github.io/revive/

- `index.html`: home page.
- `privacy/`: privacy policy (linked from the Play Store listing).
- `terms/`: terms of service (with ads and purchases Play counts the studio as a trader and asks for them; the game's Settings links them).
- `delete/`: how to delete the data the game keeps and sent (the Play Console data safety form links it).

Plain HTML and CSS, no build step. The Fredoka font (SIL Open Font License, `fonts/OFL.txt`) is served from here, so the site makes no requests to other servers.
